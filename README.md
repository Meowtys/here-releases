# Here! — Public Releases

Official public Android APK releases and in-app OTA update channel for **Here!**, an on-device face-scan attendance app for student organizations and recurring events.

- 🌐 **Web Portal & Overview:** [youre-here.vercel.app](https://youre-here.vercel.app)
- 📦 **Latest APK Download:** [Releases](https://github.com/Meowtys/here-releases/releases/latest)

## Features
- **On-Device Face Recognition:** Powered by Google ML Kit and TensorFlow Lite (MobileFaceNet) — matches returning attendees in milliseconds directly on the phone with no external cloud vision costs.
- **Offline-First Multi-Checker Sync:** Backed by Cloud Firestore so multiple checkers can scan attendees simultaneously across entrances, even without venue reception.
- **Groups, Roles & Audit Logs:** Workspaces with Owner, Admin, and Member permissions, approval-gated join codes, and activity audit logs.
- **Events & Live Analytics:** Multi-day and multi-session scheduling, live turnout and check-in velocity charts, and 1-tap CSV exports.
- **Verified In-App Updates:** Automatic and manual update checks with SHA-256 checksum verification before installation.
